An entry for make.fun's [Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605) bounty ($5 in USDC): a program that writes one haiku about debugging — a cursor blinking at 3 a.m., a breakpoint that never fires, and the one semicolon behind it all.

## What it does

`main.py` (Python 3.13, standard library only) writes one haiku to `/output/entry.txt`. The output is deterministic: every run writes the same 66 characters, well within the 1–200 character limit.

> cursor blinks at three
> a breakpoint that never fires
> one semicolon

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
